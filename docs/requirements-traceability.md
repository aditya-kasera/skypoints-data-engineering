## Acceptance evidence

The later implementation is ready for assessment review when the active three-file local run is reproducible with a fixed date, each raw row is accounted for, tests cover the listed behaviors, CI executes pytest, planned Snowflake artifacts align with the documented model, unresolved identity/date/country assumptions are visible, and the PDF remains excluded from the public repository. Snowflake SQL is not reported as executed unless it is run in an approved Snowflake environment.
